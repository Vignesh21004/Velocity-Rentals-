🚗 Velocity Rentals

📌 Project Overview

Velocity Rentals is a vehicle rental management system designed to simplify and organize the process of renting vehicles.

The project provides functionality for managing vehicles, customers, bookings, rental details, and payments through a structured and user-friendly system.

🎯 Objectives

- Manage available rental vehicles
- Maintain customer information
- Handle vehicle bookings and rentals
- Track rental and return details
- Manage payment information
- Improve the overall vehicle rental process
